# The Petit Club · Little Explorers Barcelona

Web oficial de **The Petit Club** — experiencias infantiles a medida para cumpleaños, bodas y eventos en Barcelona.

## Estructura

- `index.html` — la web (copia publicable de `The Petit Club.dc.html`, que es el archivo fuente original en formato DC)
- `support.js` — runtime que renderiza la página
- `assets/img/` — fotografías optimizadas para web
- `assets/icons/` — iconografía de marca (línea monotrazo oliva)

## Publicación

Pensada para GitHub Pages: *Settings → Pages → Deploy from branch → main /(root)*.
(En repositorios privados, GitHub Pages requiere plan de pago; si se hace público, es gratuito.)
